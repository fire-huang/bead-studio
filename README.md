# 豆造 · 3D 拼豆工作台

把图片变成可编辑的拼豆图纸。上传图片、调整配色与细节、查看哑光 3D 预览，再导出图纸和材料清单。

[在线体验](https://bead-studio-5xr.pages.dev/) · [进入工作台](https://bead-studio-5xr.pages.dev/studio) · [观看 30 秒短片](https://bead-studio-5xr.pages.dev/#film)

## 功能

- 图片转拼豆：完整保留或居中裁剪，可调整裁剪位置、近白背景过滤及轮廓细节。
- 16–256 颗宽的图案，最长边上限 256 颗；内置 256 色演示色卡，也可导入品牌色卡。
- 平面编辑：画笔、橡皮、填充、吸色、整色替换、相近色合并、撤销与重做。
- Three.js 哑光 3D 预览，支持旋转和缩放，展示豆子的孔洞与厚度。
- 照图拼豆：颜色高亮、行列定位、逐行标记完成、缩放和平移。
- 本地作品库、自动备份、JSON 导入导出及键盘快捷键。
- 制作图 PNG、3D 效果图 PNG、材料用量 CSV、可编辑作品 JSON、分页打印或另存 PDF。
- 响应式产品首页与点击播放的 30 秒短片。

图片转换在浏览器本地进行，作品保存在当前浏览器。运行依赖随网站提供，无需外部 CDN 或服务端。

## 本地运行

```sh
git clone https://github.com/fire-huang/bead-studio.git
cd bead-studio
python3 -m http.server 5173
```

打开 [首页](http://localhost:5173/dist/) 或 [工作台](http://localhost:5173/dist/studio.html)。本地服务使用文件路径；线上 `/studio` 由 Cloudflare Pages 处理。

## 开发与检查

需要 Node.js 22 或更高版本。

```sh
npm ci
npm test
```

`npm run build` 运行相同的自动检查；项目为静态 HTML、CSS 和 JavaScript，无额外编译步骤。当前包含 17 项检查，覆盖转换、色卡、快捷键、画布视图及作品流程。

- `dist/`：可直接部署的网站文件。
- `dist/vendor/`：随站点提供的 Three.js 运行依赖及其许可证。
- `tests/`：自动检查。
- [CLOUDFLARE.md](CLOUDFLARE.md)：GitHub → Cloudflare Pages 自动部署说明。

## 使用提示

默认色卡是演示色卡，不对应真实品牌商品。采购前请导入并核对品牌色卡；屏幕颜色和实物可能存在差异。

品牌色卡 JSON 格式：

```json
[{"id":"色号","hex":"#ffccaa"}]
```

色卡支持 1–256 种颜色，色号需唯一。

作品库最多保留最近 12 份副本或备份。浏览器存储按网址隔离，清理浏览器会删除本地记录；迁移网站或设备前请导出 JSON。

当前没有账号、云同步、商城或商家库存。3D 为平面拼豆的孔洞与厚度预览，暂不支持多层立体搭建及 3MF 导出。分页图纸用于阅读，不保证打印原尺寸。
