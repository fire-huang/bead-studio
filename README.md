# 豆造 · 3D 拼豆工作台

浏览器内处理图片的拼豆创作工具。使用 Three.js 实例化几何体呈现带孔洞的拼豆，支持平面编辑、本地保存、色卡导入和图纸导出。

## 本地运行

在项目目录运行 `python3 -m http.server 5173`，访问 http://localhost:5173/dist/ 。所有运行依赖已经放入 dist/vendor，无需外部 CDN。

## 第一版范围

- 上传、居中裁剪及裁剪位置、网格宽度与颜色上限、近白背景过滤
- 3D 旋转缩放、平面画笔、橡皮、吸色、连通区域填充、整色替换、撤销重做
- 作品自动保存，JSON 导入导出
- 带坐标色号的制作图 PNG、3D PNG、24×24 分区打印、CSV 用量
- 支持自定义品牌色卡，默认演示色号不对应真实品牌

色卡格式：`[{"id":"色号","hex":"#ffccaa"}]`，1–256 色且色号唯一。

## 已知边界

本地作品库最多保存最近12份副本或备份；没有账号、云同步、商城或商家库存。近白过滤不是主体分割。图片映射使用 Lab 感知色差、色差收益选色与可选轻量锐化，在后台工作线程中运行。完整保留模式的最长边上限为256格，长图会按比例缩小。屏幕颜色与真实拼豆可能有差异，采购前请核对色卡。

## 精度优化

48/96/160/256颗宽预设（新作品默认96）；平面编辑支持100%–1600%缩放、拖动画布和放大显示色号。高颗数作品自动简化豆子几何体；高清图纸适配导出画布尺寸，原版本作品仍可恢复。

验证：`node --test tests/conversion.test.js`。

## 颜色扩展

演示色卡扩展至256个唯一颜色，保留旧版32色编号和颜色；恢复旧版演示作品时自动扩展可选颜色，现有网格不变。默认颜色上限64，提供32/64/128/全部快捷选择；自定义品牌色卡的上限随实际色数变化。颜色上限随作品JSON一起保存。

## 3D哑光展示

豆子和底板使用漫反射材质，不产生镜面高光。中性白主光与柔和半球光保留孔洞、侧壁和厚度明暗，避免暖色强光使颜色泛白。大图简化几何体与普通几何体共用同一哑光材质；3D效果图导出沿用当前展示。

## 产品介绍首页

首页现为面向初次访问者的产品介绍页，原工作台完整保留在 `studio.html`，共用原有浏览器作品存储。首页的原始像素图、3D小花和网格制作图使用同一份示例网格。主要操作为“开始创作”，直接进入工作台；页面不再提供预约演示入口。未加入客户评价、客户Logo、用户量或效率数字。

## 视觉与交互更新

首页和工作台统一采用深石墨背景、暖白文字及珊瑚橙强调色。首页可切换原图、立体预览和制作图纸；手机导航支持展开、关闭及键盘操作。滚动渐入遵循系统减少动态效果设置。工作台的编辑、保存和导出功能沿用现有实现，打印图纸仍使用白色背景。

## 创作与跟拼流程

- 调色盘默认只显示已用颜色，按用量排列，可搜索色号、查看用量和少量用色提示。
- 可填写限定色号，仅使用这些颜色重新转换；相近色合并有前后色块预览、自动副本和撤销。
- 跟拼支持当前色高亮、行列定位、逐行完成标记与本地进度恢复；编辑图案会清除旧进度。
- 重新生成、上传新图、导入和切换作品前自动备份；手工修改后重新生成需确认。作品库保留最近12份，支持JSON导出，原图与撤销历史不随副本保存。
- 新增32/48颗入门预设与预计尺寸、网格颗数上限；手机画布前提供上传入口。
- 分页打印支持8–64颗边长的分区，提供行列范围和每区材料量；为可读图纸，不保证打印原尺寸。
- 品牌色卡仍需导入核验数据，演示色号不映射真实商品。

验证：`node --test tests/*.test.js`（13项），并检查限定色号转换、相近色合并/撤销、作品副本和进度刷新恢复。

## 首次使用与照图制作

界面将“跟拼”改名为“照图拼豆”，明确用于照着图纸制作实物。首次进入工作台展示上传、调整、照图制作、保存导出的四步介绍，关闭后在本设备记住，作品名称旁的“使用指南”可随时重看。

照图模式下可直接拖动画布，轻点才定位行列；支持鼠标滚轮缩放、双指捏合缩放与移动。切换行保留横向位置，标记完成和轻点定位不强制重置视图。提供定位当前行、方向按钮和适应画布。拖动设有边界，避免图纸完全移出视野。浏览器已验证放大拖动、首次介绍不重复弹出及手机布局；双指交互仍需真机触控验证。

## 快捷键

1/2/3切换立体、平面和照图模式；B/E/G/I/H选择画笔、橡皮、填充、吸色和移动。平面或照图模式中，方向键移动图纸，Shift加速，+/-缩放，0适应画布，空格按住可临时拖动（不切换当前工具）。照图模式支持[和]换行、Enter标记本行、C定位当前行。Ctrl/Command+S保存，Ctrl/Command+Z撤销，Shift+Z或Ctrl/Command+Y重做。?或画布下方按钮打开快捷键说明。

输入框、可编辑文字、表单、中文输入法组合期间和弹窗中不触发快捷键；聚焦按钮的Enter和空格仍使用原生行为。窗口失去焦点时清除临时移动状态。验证包含17项测试与浏览器模式切换、工具切换、方向键、缩放、换行、输入保护和弹窗保护。
